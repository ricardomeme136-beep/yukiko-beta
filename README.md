# Yukiko Restaurant — Website Remake

A responsive static website concept for Yukiko, built in HTML, CSS and JavaScript, using photographs from the Yukiko website with permission provided by the requester.

## Run locally
Open `index.html` in a browser. Or use `python -m http.server 8000` and visit http://localhost:8000.

## Publish
Upload the three website files to any static web host (Cloudflare Pages, Netlify, Vercel, GitHub Pages, etc.). No build step is required.

## Important notes before replacing the live website
- Original photos and PDF menu are referenced by URL from `yukiko-restaurant.de`. They therefore require an internet connection and continued hosting by the original site. Download/host those assets on your own domain for independence.
- The booking form opens the visitor's email app with a prewritten reservation request. It does NOT submit directly to a restaurant booking system or confirm availability. To receive bookings reliably, connect a backend/email service or existing reservation provider.
- The footer's Impressum/Datenschutz link is a temporary link to the original site; point it to exact verified legal pages before launch.
- Verify opening hours, current menu/prices, reservation rules, brand/trademark permission, and content before going live.
- This is a modernized adaptation, not a pixel-perfect recreation of the existing WordPress theme.
